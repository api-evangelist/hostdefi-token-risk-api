# hostdefi-token-risk-api
Token-safety risk API from HostDeFi, a non-custodial multi-chain DEX (Solana + 7 EVM chains). Returns one-call A+–F safety verdicts with 0–100 scores from on-chain checks (mint/freeze authority, LP lock, holder concentration, honeypot/tax flags), plus pre-graduation signals, radar alerts, rug obitua
